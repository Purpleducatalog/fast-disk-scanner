## 💡 Overview

**Fast Disk Scanner** is a high-performance storage analysis tool designed to index, map, and visualize disk contents at incredible speeds. Whether you're recovering space on a full drive, investigating performance issues, or auditing storage for compliance — this tool delivers results in seconds where others take minutes.

Built on a multithreaded C++ core with an optional Rust accelerator, it can index millions of files in under a minute while maintaining a footprint under 100 MB of RAM.

### What It Does

| Function | Description |
|----------|-------------|
| 🔍 **Index** | Rapidly scan entire drives |
| 📊 **Analyze** | Categorize by type, age, size |
| 🎨 **Visualize** | Treemap, sunburst, heatmap |
| 🧹 **Clean** | Identify reclaimable space |
| 🔁 **Compare** | Diff two snapshots |
| 📤 **Export** | CSV, JSON, HTML reports |
| 🔎 **Search** | Ultra-fast file lookup |

### Basic Workflow

1. **Select Drive** → click drive icon
2. **Start Scan** → press `F5` or click Scan
3. **Wait for Indexing** → progress bar shows
4. **Explore Treemap** → click cells to drill down
5. **Search Files** → use search bar
6. **Review Findings** → sort by size, type, age
7. **Take Action** → delete, move, or export

### Common Search Queries

```
size:>1GB              → files larger than 1 GB
type:video             → all video files
age:>1year             → files older than a year
dupe:true              → duplicate files
ext:.tmp OR ext:.log   → by extension
path:C:\Temp           → specific folder
```

## 🛠️ Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| ❌ Scan fails | Permission | Run as admin |
| ❌ Drive not shown | Not mounted | Mount drive |
| ❌ Slow scan | HDD | Use SSD cache |
| ❌ High RAM | Too many files | Increase limit |
| ❌ Treemap blank | Rendering bug | Update GPU driver |
| ❌ Search hangs | Large index | Wait for completion |
| ❌ Export fails | Disk full | Free space |
| ❌ Cleanup blocked | Locked file | Close app using file |
| ❌ Crash on scan | Corrupt file | Skip with filter |
| ❌ macOS permission | Full Disk Access | Enable in settings |

## ❓ FAQ

**Is it really fast?**
Yes — up to 10× faster than traditional scanners.

**Is it safe to clean?**
Yes, with safe mode enabled, only truly deletable files are selected.

**Does it work on network drives?**
Yes, but performance depends on network speed.

**Can I scan multiple drives?**
Yes, one after another or in parallel.

**Does it index file contents?**
No, only metadata. Content search is not supported.

**Is it free?**
Yes, open source under MIT license.

**Does it collect telemetry?**
No — fully offline and private.

**Can I schedule scans?**
Yes, via CLI and task schedulers.

**What about Linux filesystems?**
Supports ext4, btrfs, xfs, and more.

**Does it work on USB drives?**
Yes, including exFAT and FAT32.
